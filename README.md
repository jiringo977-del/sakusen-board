# 作戦ボード

学童野球の守備位置を、指で動かして説明する作戦ボードです。

- 走者の状況（8パターン）・中間守備／前進守備
- アウトカウント、右打者／左打者・打順によるシフト
- 守備の動きは黄色の矢印、ボールの動きは黒い点線の矢印で残ります
- コーチャー2人をフィールド外に待機

## スマホのホーム画面に置く

1. 公開URLをSafari（AndroidはChrome）で開く
2. 共有ボタン →「ホーム画面に追加」

一度開けば、電波のない場所でも使えます。

## 更新するとき

`index.html` を差し替えたら、`sw.js` の `sakusen-board-v1` の数字を1つ上げてください。
